# rangos organizaciones

| Rango                  | Beneficio                                                                                                                   |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| **Banda Cobre**        | Pack inicial de 20 armas de cada tipo autorizado para su nivel.                                                             |
| **Banda Bronce**       | 2 espacios adicionales para armamento o almacén.                                                                            |
| **Banda Plata**        | 2 espacios adicionales y vehículo exclusivo de la banda.                                                                    |
| **Banda Oro**          | Base propia mapeada para la organización.                                                                                   |
| **Escalafón superior** | Mafia Cobre, Mafia Bronce, Mafia Plata y Mafia Oro, con beneficios de contrabando y lavado según aprobación administrativa. |

## Condiciones para organizaciones gratuitas

* Demostrar mérito, fidelidad y continuidad en el proyecto de rol.
* Mantener un rol full serio, respetuoso y de calidad.
* Participar en eventos del servidor; algunos rangos pueden entregarse como recompensa.
* Aceptar que el Staff puede retirar los beneficios cuando haya inactividad, toxicidad o incumplimiento.
