# README

## Servidor de rol en vivo · Full Serio

Bienvenido a la documentación oficial de **COL EXPUESTA RP**. Aquí encontrarás las normas, procedimientos y guías necesarias para disfrutar un rol serio, justo y entretenido.

{% hint style="warning" %}
El desconocimiento de las normas no exime de su cumplimiento.
{% endhint %}

## Antes de entrar a la ciudad

* Lee la [normativa general](/broken/pages/2dca710d7d4e7f513286c16a66df837e83ee6ba9).
* Conoce las reglas específicas de tu rol: civil, seguridad, EMS o organización ilegal.
* Si tienes una duda o deseas proponer una facción, abre un ticket al Staff.

## Principios de la comunidad

* Respeto a todos los jugadores.
* Interpretación realista y coherente.
* Cero toxicidad, abusos o rol forzado.
* Las decisiones del Staff se deben tratar por ticket, nunca rompiendo el rol.

**COL EXPUESTA RP** es una comunidad colombiana donde cada historia cuenta.
