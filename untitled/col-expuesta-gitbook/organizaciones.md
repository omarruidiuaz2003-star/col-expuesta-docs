# organizaciones

El entorno ilegal se regula para asegurar historias de calidad, balance y competencia sana.

## Límite de miembros

Cada banda o agrupación ilegal tiene un máximo de **6 integrantes**. El límite aplica a la lista oficial, la base y los roles activos. La única excepción es el máximo especial indicado para el Robo al Banco Central.

## Evolución

Las organizaciones progresan mediante rol constante, dominio narrativo del territorio, lealtad y evaluación del Staff. No es un sistema de pago para ganar.

Una organización puede perder rango y beneficios por toxicidad, inactividad o un nivel de rol deficiente.
